# amble

一个极简的心流时间法（Flowtime Technique）计时器。

> 目前还处于早期开发阶段

## 构建

```bash
# 安装依赖
npm install

# 开发模式
npm run tauri dev

# 打包（产物在 src-tauri/target/release/bundle/）
npm run tauri build
```


## 功能

- **正计时工作模式**：开始即进入专注，不设倒计时
- **自动计算休息时长**：暂停时按你设定的比例自动算出应休息的时间
- **时间块视图（Flow）**：今日工作/休息块的可视化时间线，支持 30m / 1h / 2h 三种行距
- **快捷补录（Quick Add）**：手动添加漏记的专注/休息时间块
- **统计（Stats）**：周/月/年维度的专注时长、休息占比、柱状图，支持 ← → 翻页
- **画中画悬浮窗**：最小化后也能随时看到计时状态
- **数据本地存储**：SQLite 持久化 + 每日自动备份（保留 7 天）

## 使用方法

### 计时

| 操作 | 按钮 | 说明 |
|------|------|------|
| 开始专注 | ▶（圆形播放键） | 计时器正计时，界面顶部和中间各有一个 |
| 暂停 | ⏸（圆形暂停键） | 自动计算休息时长 = 已专注时长 × 比例 |
| 开始休息 | Start Rest | 从计算的休息时长开始倒计时，结束自动回到待机 |
| 继续专注 | Resume | 从暂停处继续累计 |
| 结束会话 | End Session | 结束整个工作+休息循环，存入记录 |

### 休息比例

- 默认 20%（专注 5 分钟 → 休息 1 分钟）
- 主界面滑块实时调节，暂停状态下调节会同步重算当前休息时长
- 显示格式如 `20% ≈ (work 5:1)`，约等号表示比例取整后的近似值

### 时间块视图

- 计时页下滑即可看到今日的时间线
- 绿色块 = 专注，灰色块 = 休息
- 行距可通过右上角 `2h` 按钮在 30m / 1h / 2h 间切换
- 跨越行界的块会被强制拆行（拆开的部分无圆角）

### 快捷补录

- 选择 Focus / Break → 输入分钟数 → 点 ＋
- 专注块会自动按当前比例计算对应的休息额度

### 统计

- 顶部滑块切到柱状图图标
- Week / Month / Year 切换粒度
- 顶部 ← → 翻看历史周期
- 柱状图高度随数据量自适应

### 悬浮窗

- 窗口右上角画中画图标开关
- 悬浮窗置顶显示当前计时，可拖拽，悬停出现关闭按钮
- 休息状态下数字变为绿色

### 设置

- 顶部滑块切到齿轮图标
- 可设置默认休息比例，自动保存，下次启动生效



### 前置要求

- Node.js ≥ 18
- Rust ≥ 1.77
- Windows 需要 Visual C++ Build Tools 与 WebView2

### iOS 自用构建

iOS 构建需要 macOS，Windows 用户可通过 GitHub Actions 云端构建：

1. 仓库 Actions 页面 → **Build iOS (unsigned IPA)** → Run workflow
2. 构建完成后下载 artifact（未签名 IPA）
3. 用 [Sideloadly](https://sideloadly.io/) 登录 Apple ID 签名并安装到 iPhone（免费账号 7 天过期，需每周重签）
